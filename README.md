# A527 BSP SDK (monorepo)

Allwinner A527 / sun55iw3 Tina AIOT **V1.4.6** DDK stack, vendored into one repository for ROCKNIX and other distros.

## Layout

```
kernel/          # lichee/linux-5.15 + allwinner-bsp → build with CONFIG_AW_GPU_TYPE="mali-g57"
device/          # board DTS + defconfig (see configs/pro2_linux_aiot, configs/default)
libgpu/mali-g57/ # proprietary libmali wayland/gbm blob (match kernel mali-valhall DDK)
```

## Kernel config (Buildroot DDK profile)

Use `device/configs/default/linux-5.15/bsp_defconfig`:
- `CONFIG_AW_GPU_TYPE="mali-g57"`
- no `CONFIG_AW_DRM_PANFROST`

Cubie A5E board DTS: `device/configs/pro2_linux_aiot/linux-5.15/board.dts` (or ROCKNIX vendored DTS).

## libmali userspace

Wayland stack (gcc-10.3 toolchain build):
`libgpu/mali-g57/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/wayland/`

See `aw_version` / `readme.txt` in that directory for Vulkan WSI layer setup.
